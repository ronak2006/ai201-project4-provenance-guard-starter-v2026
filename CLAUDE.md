## Project Overview

Provenance Guard is an AI-detection web service (Flask/Python) for the AI201 course. It detects whether submitted text was written by a human or generated by an AI, using two signals: a language model perplexity score and stylometric text analysis. Everything runs locally — no API keys required.

**Python version:** 3.11, 3.12, or 3.13 only (NOT 3.14).

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python test.py          # validates environment
python detector.py      # downloads GPT-2 model (~550 MB, do once before class)
```

## Architecture

### Request flow for `POST /submit`

1. Extract `text` and `creator_id` from JSON body
2. `detector.model_signal(text)` → perplexity-based score 0.0–1.0 (low = human-like)
3. `stylometry.style_signal(text)` → combines three metrics → score 0.0–1.0
4. `scoring.combine_signals(model_score, style_score)` → weighted average
5. `scoring.score_to_label(combined_score)` → `"human"` / `"unsure"` / `"ai"` + label text
6. `audit.log_decision(...)` → appends to `logs/audit.jsonl`
7. Return JSON with `content_id`, `guess`, `confidence`, `label`, `model_score`, `style_score`

### Key files and their roles

| File | Role | Modify? |
|------|------|---------|
| `app.py` | Flask routes: `/ping`, `/submit`, `/appeal`, `/health`, `/log` | Yes — build `/submit` and `/appeal` |
| `config.py` | All thresholds, weights, rate limits, model name | Yes — values only |
| `detector.py` | Signal 1: GPT-2 perplexity scoring (given) | No |
| `stylometry.py` | Signal 2: Three style metrics — stubs to implement | Yes — implement stubs |
| `scoring.py` | Combine signals, map score to label — stubs to implement | Yes — implement stubs |
| `audit.py` | Append-only JSONL audit log (given) | No |
| `scenarios.py` | Test cases for five acceptance criteria (Unit 8) | Yes |

### Configuration (`config.py`)

Key tuneable values:
- `WEIGHT_MODEL_SIGNAL` / `WEIGHT_STYLE_SIGNAL` — signal weights (default 0.5/0.5)
- `HUMAN_THRESHOLD` = 0.35, `AI_THRESHOLD` = 0.65 — label cutoffs
- `RATE_LIMITING_ENABLED` — set `True` in Unit 8; also uncomment `@limiter.limit(...)` in `app.py`
- `RATE_LIMIT_PER_MINUTE`, `RATE_LIMIT_PER_DAY`

Environment variable overrides: `HOST`, `PORT`, `AI201_DEBUG`, `AI201_RATE_LIMITS`, `AI201_DETECTOR_MODEL`.

### Stylometry stubs to implement

`sentence_length_spread()` — std dev of sentence lengths; `type_token_ratio()` — unique/total words; `punctuation_density()` — punctuation relative to text length. Each returns a float; `style_signal()` combines them into 0.0 (human-like) → 1.0 (AI-like).

### Audit log format (`logs/audit.jsonl`)

One JSON object per line with fields: `timestamp`, `content_id`, `creator_id`, `guess`, `model_score`, `style_score`, `combined_score`, `label`, `status`. Appeals add `event="appeal"`, `reasoning`. Rate-limit rejections add `event="rejected"`, `reason="rate_limited"`.
